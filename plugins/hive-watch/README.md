# Hive Watch

Attention for self-hosted agents: what they keep an eye on, and when they
wake up on their own. Needs **Remote Agents**.

## Getting started

1. Open a self-hosted agent and go to the **Attention** tab.
2. Turn on **Attention**.
3. Ask the agent to follow a thread, watch a pull request, or check back
   later. Its Interests, watches, and timers show up in the tab.

## What it adds

- **Attention** tab on self-hosted agents, backed by buzz-host.
- **Interests:** ongoing responsibilities the agent reviews.
- **Watches:** wake the agent when a matching message arrives.
- **Timers:** wake the agent on a schedule.
